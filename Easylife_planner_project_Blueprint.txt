Project Context:
Project Name: Easylife Planner.

Objective: A dashboard planner to manage work and time for students and workers.

Design Philosophy: Zero complex UX/UI; the user can see all tools in one view without clicking back and forth.

Frontend Architecture
Tech Stack: React (JSX) and Tailwind CSS. The current development environment is running directly in the browser via CDN using Babel and Live Server in an index.html file.

Left Sidebar (Static): Houses quick navigation links to the main Dashboard, Calendar, Statistics, and Settings.

Center Workspace (Dynamic): Features a 7-column Daily Routine board to assign custom subjects to specific days (e.g., Biology on Monday, Physics on Tuesday). Below the routine board is a Task Table with headers for Done (checkbox), Name, Priority, and Due Date.

Right Sidebar (Animated Overlay): Remains hidden until the user clicks a specific task, at which point it slides in from the right edge to display extended task descriptions, sub-tasks, and notes.

Backend & System Requirements
Database Integration: A central database management system must seamlessly link the tasks, routine board, and an interactive calendar together.

Authentication: Requires a secure online login system.

Notifications: Needs an automated system to send task alerts via email or Discord chat.

Data Visualization: Requires a dedicated Statistics page with charts mapping daily routines to show user progress and build motivation.
